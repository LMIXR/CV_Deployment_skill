# Field Precision

空间像一张留有工作余量的工程图。大的留白容纳判断，小的刻度承载秩序；形体之间的距离与形体本身同样重要。每一条基线、每一个转角都应经过细致推敲，让精确来自关系，而不是堆叠装饰。

颜色只承担少量明确职责。温暖的纸色提供安静底面，深墨绿色形成结构，橙色标记发生变化的位置。色彩保持克制，用精心校准的明度差分清前后层次，使作品在缩小之后依然清楚。

形状从平面走向实体。薄片、框线与节点共享同一套几何语言，层层递进，却仍能看见彼此的连接。细节应体现熟练制图者的耐心：轮廓准确，线宽稳定，局部密度服务整体节奏。

字体像结构中的受力构件。宽大的字形建立重心，等宽小字提供定位，中文保持清晰而松弛。文字只留下必要的名称和线索；字号与空白经过反复调节，让阅读顺序自然发生。

最后的打磨依靠减法。删除没有承载信息的线条，收紧松散的对齐，调平字与图的重量。完整性来自对边距、节奏和比例的持续修正，使成品像一件被认真制作的工具，值得长期使用。
